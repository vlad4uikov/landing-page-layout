# Museum Landing Page
A static landing page designed as a digital showcase for a museum in New York. The website introduces visitors to the museum's exhibitions and collections, featuring selected artworks and historical exhibits, including paintings, sculptures, and statues.

The main focus of this project is visual presentation, page layout, responsive design, and styling.
